🚀 HOW TO USE

IMMEDIATE TESTING (2 MINUTES):

  1. Install dependencies:
     $ npm install

  2. Configure API key:
     $ echo "TAVILY_API_KEY=your_key_here" > .env

  3. Start server:
     $ npm start

  4. Open browser:
     → http://localhost:3000

  5. Test:
     - Convert example-mop.txt to .docx
     - Upload to web interface
     - Select domain: "IPCORE"
     - Check "Use server-side proxy"
     - Click "Analyze MOP"
     - Review scores and recommendations
