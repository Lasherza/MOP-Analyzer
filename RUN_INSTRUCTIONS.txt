🚀 QUICK START (< 5 MINUTES)
────────────────────────────────────────────────────────────────────────

1. CONFIGURE ENVIRONMENT
   cp .env.example .env
   # Edit .env and set:
   #   X_API_KEY=your-secure-api-key-here
   #   TAVILY_API_KEY=your-tavily-key  (optional but recommended)

2. START SERVICES
   docker-compose up -d

3. WAIT FOR SERVICES (30 seconds)
   docker-compose ps  # All should show "Up (healthy)"

4. ACCESS APPLICATION
   • Frontend:  http://localhost:8080
   • Backend:   http://localhost:3000
   • API Docs:  http://localhost:3000/api/docs

5. TEST WITH SAMPLE
   curl -X POST http://localhost:3000/api/analyze \
     -H "X-API-KEY: your-api-key" \
     -F "mop=@samples/full_mop.docx" \
     -F "category=IPCORE" | jq

📊 SCORING ALGORITHM
────────────────────────────────────────────────────────────────────────
Each MOP section scored 0-10 based on:
  • Presence (30%)      - Content exists and is substantial
  • Clarity (25%)       - Steps are specific and actionable
  • Verifiability (20%) - Includes validation steps
  • Safety (15%)        - Risk assessment and impact analysis
  • Compliance (10%)    - Matches ITIL4 and Telco best practices

Total Score = PreChecks(35%) + OpSteps(40%) + Rollback(25%)

❓ TROUBLESHOOTING
────────────────────────────────────────────────────────────────────────

Backend won't start:
  ✓ Check .env file exists with X_API_KEY
  ✓ docker-compose logs backend

Frontend shows 401 errors:
  ✓ Ensure VITE_API_KEY matches backend X_API_KEY

Tavily not working:
  ✓ Check TAVILY_API_KEY is set
  ✓ App works without it, just reduced category scoring

Port conflicts:
  ✓ Edit docker-compose.yml to change ports
  ✓ Default: 3000 (backend), 8080 (frontend)
